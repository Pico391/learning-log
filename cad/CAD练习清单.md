## ① 法兰盘（和轴承几乎一样，5 分钟）
练：`CIRCLE` + `ARRAY`（环形阵列）
1. `CIRCLE` 画外圆（法兰盘外缘）
2. `CIRCLE` 画中心孔
3. 画一个螺栓小圆孔，贴着某一圈
4. `ARRAY` → 环形阵列 → 中心选圆心 → 数量 6~8 → 阵成一圈螺栓孔
5. 加中心线 + 尺寸标注

---

## ② 齿轮（最炫，练阵列）
练：`ARRAY` + `POLYGON`，视觉冲击强
1. `CIRCLE` 画外圆（齿顶圆）Ø100
2. `CIRCLE` 画内圆 r=40（辐板镂空）
3. `CIRCLE` 画中心孔 Ø20
4. 在圆周上用 `RECTANG` 画一个小矩形（一个齿），贴着外圆
5. `ARRAY` → 环形阵列 → 中心点选齿轮圆心 → 数量 20 → 阵成一圈
6. `TRIM` / `FILLET` 把齿和圆修顺
7. 加中心线 `CENTERLINE` + 尺寸标注 `DIM`

## ③ 六角螺母（最简单，练多边形）
练：`POLYGON` + `TRIM`，5 分钟出图
1. `POLYGON` → 边数 **6** → 中心点 → "外切于圆" → 半径 25，画正六边形
2. `CIRCLE` 画内螺纹孔 Ø12（六边形中心）
3. `CHAMFER`（倒角）把六边形顶角斜一点
4. 画中心线 `CENTERLINE` 穿过中心
5. 标注 `DIMDIAMETER` 标螺纹孔、`DIM` 标对边距

## ④ 阶梯轴（最实用，练矩形拼 + 镜像）★ 重点

> 套路：**画中心线 → 上半边拼三个矩形 → 镜像出下半边**。不用 OFFSET，新手最稳。

1. **画中心线**：`CENTERLINE`（或 `LINE`）画一条水平线当中轴，比如 y=200，从左边画到右边。
2. **第一段细轴**：`RECTANG` → 点 `(80,200)` → `(140,230)`。底边压在中心线上，高 30 = 代表 Ø30 轴段。
3. **第二段粗轴**：`RECTANG` → `(140,200)` → `(220,250)`。高 50 = Ø50，紧接第一段右边。
4. **第三段细轴**：`RECTANG` → `(220,200)` → `(280,230)`。高 30 = Ø30。上半边成"细—粗—细"阶梯。
5. **镜像出下半**：`MIRROR` → 框选三个矩形 → 选镜像线时**点中心线左右两个端点** → 回车。下半边自动生成。
6. **清线**：`TRIM` 把中间重叠的横边修掉，留外轮廓（中心线别删）。
7. **标注**：每段 `DIMDIAMETER` 点一下标 Ø30/Ø50；总长 `DIMLINEAR`。
   - 卡点：矩形底边怎么"贴"中心线？诀窍是 RECTANG 第一个角点的 y 坐标写和中心线一样的数字（上例都是 200）。

## ⑤ 压缩弹簧（有趣，练阵列/样条）
练：`ARRAY`（矩形阵列）/ `SPLINE`，螺旋感强
1. 画两条垂直中心线（弹簧左右边界）
2. `LINE` 画一段斜线（代表弹簧一圈侧面投影）
3. `ARRAY` → 矩形阵列 → 行数 = 圈数（如 8）→ 行偏移 = 节距（如 12）→ 复制出一摞斜线
4. 两端画水平短线"磨平"
5. （进阶）`SPLINE` 直接画一条波浪螺旋线代替斜线阵列，更逼真
6. 标注自由长度、外径 `DIM`
