# CAD 术语「人话词典」（机械制图初学者版）

> 目的：把练习册/网课里听不懂的专业词，翻译成大白话 + 生活比喻。
> 用法：遇到不认识的词，Ctrl+F 搜一下。画轴承座、阶梯轴、法兰盘都用得到。

---

## 一、零件本身

### 轴承座（bearing seat / bearing housing）
- **是什么**：一个"托着轴承的架子"。轴承是个圆珠子（你之前画的），但它不能悬空，得有个底座把它架住、再用螺栓固定到机器上——这个底座+支架就是轴承座。
- **比喻**：轴承像"轮子"，轴承座像"轮子的支架/轴承盒"。

### 筋板（web / gusset）
- **是什么**：连接两个零件、让它更结实的三角形薄板。轴承座里底座和圆筒之间是悬空的，加两块三角形板撑住，就像书架的三角支撑杆。
- **比喻**：乐高积木里那块三角形的加固片。

### 圆筒 / 内径 / 外径
- **圆筒**：轴承座上方那个空心圆柱，轴承就塞在里面。
- **内径（Ø30）**：圆筒里面那个孔的直径（轴承外径比它略小，正好套进去）。
- **外径（Ø50）**：圆筒外面的直径。

## 二、看图的方法（最容易懵的一堆词）

### 三视图（three views）
- **是什么**：一个零件从**三个方向**各拍一张"照片"：正前方（主视图）、正上方（俯视图）、正左方（左视图）。
- **为什么**：一张图看不全一个立体东西，三个角度拼起来才完整。
- **比喻**：你给人描述一个手机壳，得说"正面长啥样、顶面长啥样、侧面长啥样"。

### 主视图 / 俯视图 / 左视图
- 主视图 = 从正前方看（最常用，放最左边）
- 俯视图 = 从正上方往下看（放主视图正下方）
- 左视图 = 从正左方看（放主视图正右方）

### 长对正、高平齐、宽相等（九字真言）
- 这是三视图对齐的规矩：
  - **长对正**：主视图和俯视图，左右宽度要对齐（上下对齐）
  - **高平齐**：主视图和左视图，上下高度要对齐（左右平齐）
  - **宽相等**：俯视图和左视图，前后宽度要相等
- **比喻**：三张照片是同一个东西的不同面，边缘必须严丝合缝对上，不能各画各的。

### 剖视图（section view）
- **是什么**：想象用一把大刀把零件**从中间切开**，然后把"切面"这半边转过来给你看切面长啥样。
- **为什么**：圆筒里面是空的、有孔，从外面看全是实线，看不出里面。切开就能看到内部结构和壁厚。
- **比喻**：切西瓜——整个西瓜看不出瓤，切开才看得到。剖视图就是"切开的图"。

### 剖面线 / 剖面符号（HATCH）
- **是什么**：剖视图里，被切到的"实心材料"部分，要画上一层层**45°斜线**（像斑马纹），表示"这里是被刀切到的实心金属"。
- **命令**：`HATCH`（快捷键 `H`），选图案 ANSI31。
- **比喻**：切开的西瓜，瓜瓤部分用斜线填满，告诉你"这块是实心的、被切到了"。没画斜线的地方就是空心/孔。

### 不可见轮廓线 → 虚线（hidden line）
- **是什么**：零件背面、被挡住、从当前视角看不见的边，用**虚线（黄色 Dashed）**画出来，告诉你"这里其实有条边，只是被挡住了"。
- **比喻**：X光片——看见骨头（虚线）但皮肤挡着。

## 三、线型和图层（基本功）

### 图层（LAYER，快捷键 LA）
- **是什么**：把不同类型的线分到不同的"透明玻璃纸"上。比如所有中心线放一层、所有标注放一层、所有轮廓放一层。
- **为什么**：方便统一管理（改颜色、改线宽、一起隐藏），也是工厂制图规范。
- **比喻**：PPT 里把"背景""文字""图片"分图层，互不干扰。

### 粗实线（可见轮廓线）
- 零件**看得见的外边**，画最粗（0.5mm），黑色/白色。你眼睛第一眼看到的形状线。

### 细实线
- 尺寸线、引出线、剖面线，画细（0.25mm），青色。

### 中心线（Center，点划线）
- 标零件**对称中心**的线，一长点一短的红色线。比如轴的轴线、圆的圆心十字线。
- **比喻**：圆的"十字准星"，告诉你"这是对称轴"。

### 虚线（Dashed，黄色）
- 就是上面的"不可见轮廓线"。

### 标注层
- 专门放所有尺寸数字和文字的层，绿色。

## 四、尺寸符号

### Ø（直径符号，读作"斐"）
- 圆/孔的直径。比如 Ø30 = 直径 30mm 的孔。
- 命令：`DIMDIAMETER`（DDI）标圆/孔用这个。

### R（半径符号）
- 圆弧/圆角的半径。比如 R5 = 半径 5mm 的圆角。
- 命令：`DIMRADIUS`（DRA）标圆弧用这个。

### 线性尺寸
- 直线距离（长、宽、高）。命令：`DIMLINEAR`（DLI）。

### 均布
- "均匀分布"的缩写。比如"6个螺栓孔均布在圆周上"= 6个孔绕着圆**等间距**排一圈（用 ARRAY 环形阵列做）。

### 倒角（CHAMFER，CHA）
- 把零件的尖角切掉一小块，变成 45° 的小斜面。防止刮手、方便装配。
- 比如 C2 = 2mm 的倒角。

### 圆角（FILLET，F）
- 把尖角磨成圆弧（R5 = 半径5mm的圆弧角），减少应力集中。

## 五、常用命令一句话
| 词 | 人话 |
|----|------|
| ARRAY 阵列 | 把一个东西"复制一圈/一排"，螺栓孔就靠它 |
| MIRROR 镜像 | 画一半，翻镜子出另一半（对称零件省一半时间） |
| TRIM 修剪 | 像剪刀，剪掉多余的线段 |
| OFFSET 偏移 | 照着原线"平行挪"一段距离，画壁厚/槽用 |
| HATCH 剖面线 | 给切面填斜线，表示"这里被切到了" |

---

> 记不住没关系，画的时候遇到哪个词不懂，回来搜一下就行。
> 核心就三件事：**分层画图（图层）→ 画对形状（粗实线/中心线/虚线）→ 切开看内部（剖视图+剖面线）→ 标上尺寸（Ø/R/线性）**。
