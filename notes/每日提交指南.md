# 每日提交指南

## 每天怎么提交代码到 GitHub

打开终端（Git Bash），进入项目文件夹：

```bash
cd C:/Users/pico/Projects/learning-log
```

然后三步走：

```bash
# 1. 把改动的文件加入暂存区
git add .

# 2. 提交一个版本（写清楚你今天做了什么）
git commit -m "学完Python第6章break/continue，做了8道练习题"

# 3. 推送到 GitHub
git push
```

就这样，每天做完学习后跑一遍这三行命令就行。

## commit 消息怎么写

格式：`做了什么 + 结果/进展`

好例子：
- `学完Python第6章break/continue，做了8道练习题`
- `CAD练习：画完法兰盘，用了ARRAY阵列命令`
- `C语言：学完指针基础，写了5个指针练习`
- `修复temperature_avg.py的除零bug`

坏例子：
- `update`（太模糊）
- `今天学了很多`（没说学什么）
- `111`（毫无意义）

## 查看状态

随时可以查看当前改动状态：

```bash
git status    # 看哪些文件改了
git log       # 看提交历史
```
