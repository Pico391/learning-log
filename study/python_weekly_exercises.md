# 一、元组(tuple) 练习题（8-3 任务）

> 目标：掌握元组的**创建、索引、切片、不可变特性、解包、遍历**。
> 5 道基础题都能独立写出并运行通过，就可以在面板 8-3 任务里点 ✅ 打卡。

## 第 1 题 · 创建与索引

创建元组 `t = (10, 20, 30, 40, 50)`，分别打印：

1. 第 1 个元素（最前面那个）
2. 最后一个元素
3. 倒数第 2 个元素

<details>
<summary>答案 / 提示</summary>

```python
t = (10, 20, 30, 40, 50)
print(t[0])    # 10   —— 索引从 0 开始
print(t[-1])   # 50   —— -1 表示最后一个
print(t[-2])   # 40   —— -2 表示倒数第二个
```

提示：索引从 `0` 开始；负数索引从末尾往前数，`-1` 是最后一个。

</details>

## 第 2 题 · 切片

对 `t = (1, 2, 3, 4, 5, 6)`，用切片得到：

1. 前 3 个 → `(1, 2, 3)`
2. 最后 2 个 → `(5, 6)`
3. 中间第 2 到第 4 个（含 2 不含 5）→ `(2, 3, 4)`
4. 隔一个取一个 → `(1, 3, 5)`

<details>
<summary>答案 / 提示</summary>

```python
t = (1, 2, 3, 4, 5, 6)
print(t[:3])    # (1, 2, 3)   前3个
print(t[-2:])   # (5, 6)      最后2个
print(t[1:4])   # (2, 3, 4)   第2到第4（含头不含尾）
print(t[::2])   # (1, 3, 5)   步长2，隔一个取一个
```

</details>

## 第 3 题 · 不可变特性（元组不能改）

下面代码会报错，为什么？怎么改才对？

```python
t = (1, 2, 3)
t[0] = 100   # 报错！
```

要求：把第 1 个元素改成 100（用正确做法）。

<details>
<summary>答案 / 提示</summary>

```python
t = (1, 2, 3)
lst = list(t)      # 先转成列表，列表才能改
lst[0] = 100
t = tuple(lst)     # 改完再转回元组
print(t)           # (100, 2, 3)
```

提示：**元组一旦创建就不能改（不可变）**。要"改"只能先 `list()` 转列表、改完再 `tuple()` 转回。这是元组最经典的坑。

</details>

## 【专题】元组 vs 列表对比（8-3 第 3 任务）

> 元组和列表**都能**存一串数、都能索引 / 切片 / 遍历；
> 最大区别：**列表能改能加，元组不能**（元组"不可变"）。

照下面 4 步在 Python 里跑一遍，亲眼看看区别：

```python
print("===== 1. 都能读 =====")
t = (1, 2, 3)
lst = [1, 2, 3]
print("元组第一个:", t[0])     # 1
print("列表第一个:", lst[0])   # 1

print("===== 2. 列表能改，元组不能 =====")
lst[0] = 100
print("改完列表:", lst)        # [100, 2, 3]
# t[0] = 100   # 取消注释运行会报错：元组不支持改

print("===== 3. 列表能加，元组不能 =====")
lst.append(4)
print("列表加完:", lst)        # [100, 2, 3, 4]
# t.append(4)   # 取消注释运行会报错：元组没有 append

print("===== 4. 都能遍历、切片 =====")
print("元组切片:", t[1:3])     # (2, 3)
print("列表切片:", lst[1:3])   # [2, 3]
```

**你要做的小实验（8-3 第 3 任务就是它）：**
1. 建 `t = (1, 2, 3)` 和 `lst = [1, 2, 3]`
2. 把 `lst[0]` 改成 100，打印 `lst`（应该变）
3. **试着**把 `t[0]` 改成 100（先写在注释里猜会怎样，再取消注释运行，看报什么错）
   → 预期报错：`'tuple' object does not support item assignment`（元组不支持改）
4. 列表用 `lst.append(4)` 加一个数；元组没有 `append`（也会报错）

**一句话记忆**：元组 `()` 像"封死的盒子"——能看、能取、能切片，但**不能往里改、不能往里加**；列表 `[]` 像"开口的袋子"——随便改、随便加。记住"一个能改一个不能改"就够用了。

## 第 4 题 · 解包(unpacking)

1. 用一行把 `a, b = 1, 2` 的值互换（不用临时变量）。
2. 元组 `(x, y) = (5, 8)`，分别打印 x 和 y。
3. 写函数 `get_min_max(nums)` 返回 `(最小值, 最大值)`。

<details>
<summary>答案 / 提示</summary>

```python
a, b = 1, 2
a, b = b, a            # 交换，现在 a=2, b=1
print(a, b)

t = (5, 8)
x, y = t               # 解包：x=5, y=8
print(x, y)            # 5 8

def get_min_max(nums):
    return min(nums), max(nums)   # 返回的其实是个元组
print(get_min_max([3, 1, 9, 2]))  # (1, 9)
```

提示：等号右边是元组时，左边变量按顺序逐个接收，叫"解包"。`return a, b` 实际是 `return (a, b)`。

</details>

## 第 5 题 · 遍历（带序号）

> ⚠️ 这里的"序号"是**第几个元素（位置）**，不是按分数高低排的"名次"。
> 比如列表第 1 个元素是 88 → 显示"序号1：88分"；第 2 个是 92 → 显示"序号2：92分"。
> 想按分数从高到低排真实名次（92=第1名），得先**排序**，那是后面的知识，见底部预览。

遍历元组 `scores = (88, 92, 75, 60)`，打印每个成绩和它的**序号（第几个，从 1 开始）**。

<details>
<summary>答案 / 提示</summary>

**【新手写法 · 只用你已会的 for 循环 + 计数器】**
```python
scores = (88, 92, 75, 60)
i = 1                      # 序号，从 1 开始
for s in scores:
    print("序号", i, "：", s, "分")
    i = i + 1              # 每打印一个，序号加 1
```

**【进阶写法 · enumerate（以后会学到）】**
```python
scores = (88, 92, 75, 60)
for i, s in enumerate(scores, start=1):
    print("序号", i, "：", s, "分")
```
`enumerate(序列, start=1)` 会自动给每个元素配一个从 1 开始的编号：`i` 拿到编号，`s` 拿到成绩。它就是把上面的 `i = i + 1` 计数器帮你省了，**效果完全一样**。

**【预览：真正的"按分数排名"（以后学排序再做）】**
如果真要 92 排第1名、88 排第2名，得先把成绩从高到低排好再打印：
```python
scores = (88, 92, 75, 60)
ranked = sorted(scores, reverse=True)   # 排序：从大到小 -> [92, 88, 75, 60]
i = 1
for s in ranked:
    print("第", i, "名：", s, "分")
    i = i + 1
```
`sorted(..., reverse=True)` 是排序（你还没学），所以这一版先放着，等学到排序再回来做。

</details>

## 综合挑战（选做）

写函数 `top_two(nums)` 返回成绩里的前两名（最大和次大），用元组返回。
例如 `top_two([88, 92, 75, 60])` → `(92, 88)`。

<details>
<summary>答案 / 提示</summary>

```python
def top_two(nums):
    s = sorted(nums, reverse=True)
    return (s[0], s[1])
print(top_two([88, 92, 75, 60]))   # (92, 88)
```

</details>

# 二、字符串(string) 练习题（8-4 任务）

> 💡 字符串和元组、列表一样都是**「序列」**——索引 `s[0]`、切片 `s[1:3]`、遍历 `for c in ...` 写法**完全一样**。你练元组时已经会了这些，字符串只是把"元素"换成了"字符"，上手极快。

## 第 1 题 · 创建与索引

```python
s = "python"
print(s[0])     # 第 1 个字符
print(s[-1])    # 最后一个字符
print(s[1])     # 第 2 个字符
```

**问**：三行分别输出什么？

<details>
<summary>答案</summary>

```
p
n
y
```

`s[0]` 是第一个 `'p'`，`s[-1]` 是最后一个 `'n'`，`s[1]` 是第二个 `'y'`。

</details>

---

## 第 2 题 · 切片（含头不含尾）

```python
s = "hello world"
print(s[0:5])    # 第1到第5个（含头不含尾）
print(s[6:11])   # 第7到第11个
print(s[::2])    # 从头到尾，每隔一个取一个
```

<details>
<summary>答案</summary>

```
hello
world
hlowrd
```

`s[0:5]` 取索引 0~4 → `"hello"`；`s[6:11]` 取 6~10 → `"world"`；`s[::2]` 步长 2 → 取 0,2,4,6,8,10 位置的字符 `h l o w r d`。

</details>

---

## 第 3 题 · 遍历 + 计数（不用 `.count`）

数出 `s = "banana"` 里有几个字母 `'a'`。用 `for` 循环 + 计数器 + `if` 判断。

<details>
<summary>答案 / 提示</summary>

```python
s = "banana"
count = 0
for c in s:
    if c == 'a':
        count = count + 1
print("a 出现了", count, "次")
```

输出：`a 出现了 3 次`

要点：`count = 0` 写在循环**外面**；循环里用 `=` 赋值（不是 `==` 比较）。

</details>

## 第 4 题 · 查找某个字符（不用 `in` / `.find`）

`email = "tom@qq.com"`，判断里面有没有 `'@'`。

<details>
<summary>答案 / 提示</summary>

```python
email = "tom@qq.com"
found = "没找到"
for c in email:
    if c == '@':
        found = "找到了"
print(found)
```

输出：`找到了`

要点：先设 `found = "没找到"` 当默认值，循环里一旦碰到 `'@'` 就改成 `"找到了"`。

</details>

## 🔍 字符串方法预览（以后正式学再做，现在不要求）

字符串有很多现成方法，能少写循环：
- `s.upper()` → 全大写：`"abc".upper()` 得 `"ABC"`
- `s.count('a')` → 数出现次数：`"banana".count('a')` 得 `3`
- `s.find('@')` → 找位置：`"tom@qq.com".find('@')` 得 `3`
- `'a' in s` → 判断是否包含：`'a' in "banana"` 得 `True`

这些方法很方便，但属于"字符串章节"才系统讲，你**现在的任务不要求用**，先用手写循环把逻辑练熟就行。
